# 鼠标模式测试手册

适用版本 / 分支：`feature/mouse-mode`（基线 `origin/main` `8ac30cf2`）。

## 测试前准备

- macOS 主机已授予「辅助功能」与「输入监控」权限（鼠标注入依赖 `CGEvent` 在 `kCGHIDEventTap` 派发）。
- 一台已配对的遥控器（Siri Remote / 小米 / 通用蓝牙遥控器均可），连接状态正常。
- 打开设置页 → 「按键」分区，给任意键的任意触发绑「切换鼠标模式」（例如菜单双击）。
- 打开设置页 → 「鼠标模式」分区，确认**没有**「启用鼠标模式」开关，音量互换关、加速默认
  （baseStep 10、slope 20、maxStep 80、interval 16ms）。

## 逐步操作与预期

### 1. 无启用开关与默认零影响

1. 未绑定切换键时，正常操作遥控器各键，确认行为与此前一致（passthrough）。
2. 在「按键映射」页给任意键绑定「切换鼠标模式」（例如菜单双击）。

- 预期：页面没有「启用鼠标模式」开关；只要绑了切换键，按该键 + 触发就进入鼠标模式，
  不需要再打开任何开关；未进入时其他键仍走原映射。

### 2. 进入与退出

1. 按「切换鼠标模式」所绑的键 + 触发 → 进入鼠标模式（指针可由方向键驱动）。
2. 再次按同一键 + 触发 → 退出，遥控器恢复全部常规功能。

- 预期：切换严格按绑定槽位判定——绑双击就只在双击切换，单击不误触发；切换键在两种状态下都只做切换。
- 菜单双击绑切换、菜单单击绑上下文菜单时：单击出上下文菜单且不切模式，双击才切换。
- 蓝色反馈圈是鼠标模式的常驻指示器：进入即出现，按 `确认`（左键）、方向键、音量滚轮后都**保持显示**，
  不因点击或静止超时消失；退出鼠标模式立即消失。按左键后圈消失即为失败（见 `Bugs/2026-11-15-mouse-mode-feedback-ring-disappears-after-click.md`）。

### 3. 方向键移动（步进 + 线性加速）

1. 轻点 `上`：指针向上移动一步（约 8px）。
2. 按住 `上` 不放：约 250ms 后开始加速，移动越来越快，直到 60px/步封顶；松手立即停。
3. 同法验证 `下`/`左`/`右`。

- 预期：单击=一步；按住=线性加速；**不进入长按识别**；松手即停，指针不残留移动。

### 4. 左 / 右键与滚轮

1. 按 `确认(ok)`：鼠标左键单击（光标处激活目标）。
2. 按 `菜单(menu)` 单击：鼠标右键单击（上下文菜单）。
3. 按 `音量 +` / `音量 -`：滚轮向上 / 向下。
4. 打开「互换音量键的滚轮方向」后重测：`音量 +` 变向下、`音量 -` 变向上。

- 菜单只占用单击这一个槽位：菜单双击 / 长按仍走「按键」页里为该槽位设置的操作（例如切换鼠标模式），
  不被固定成右键。

### 5. 光标外环圈颜色

1. 设置页 → 「鼠标模式」→「光标外环圈颜色」：默认是「跟随系统」，按钮禁用。
2. 点预设色板任意色块：色块出现选中描边，进入鼠标模式后光标外环变为该颜色；不重进模式也应立即变色。
3. 用 ColorPicker 自定义任意颜色：外环同步变化。
4. 点「跟随系统」：回到系统强调色，预设色板取消选中，按钮再次禁用。
5. 退出鼠标模式后，触摸板的移动/滚动反馈圈仍保持系统强调色，不受本设置影响。

- 失败判定：改色后外环不变、重进模式才生效、影响触摸板反馈或滚动指示颜色、旧配置导入后圈色异常。

### 6. 槽位占用与只读预览

1. 进入设置页 → 「鼠标模式」，下方遥控器与「按键」页同款。
2. 占用槽位（方向键整键、OK 整键、音量 ±、菜单单击、切换键所在槽位）显示鼠标固定功能并置灰加锁，点击无反应。
3. 未占用槽位显示「按键」页里设置的操作文案，整页只读、点击不进入编辑；要修改请回到「按键」页。
4. 语音键始终走语音，不进入鼠标映射，也不在占用列表内。

### 7. 异常恢复

- 断开遥控、休眠、退出鼠标模式、权限被撤销：进行中的加速立即停止，方向键不留在按下状态。
- 任一路径不得让指针持续漂移或卡在按住状态。

## 失败判定

- 进入模式后指针不动 / 方向反了 / 加速不触发或不停止。
- 按一次方向键光标持续冲到屏幕边缘、到边缘后方向键失效（释放未送达的典型症状）。
- 日志出现 `edge=press` 但松键后没有 `edge=release` / `phase=move_stopped`。
- 切换键不按绑定槽位判定（单击误切换、双击不切换）。
- 菜单双击 / 长按被错误固定成右键，无法走映射页自定义。
- 鼠标模式页占用槽位未置灰加锁、未占用槽位不显示映射页设置，或点击竟可编辑。
- 语音键被鼠标映射吞掉。
- 松开后指针继续移动或方向键卡住。
- 已绑定切换键却按了仍不进入鼠标模式，或页面仍显示「启用鼠标模式」开关。

## 稳定功能回归

- 基础按键、自定义按键、系统媒体、语音键、组合动作在鼠标模式关闭时行为不变。
- 既有按键页筛选（`基础按键 / 自定义按键 / 系统媒体 / 输入框`）与鼠标模式分区互不干扰。

## 日志收集

- 鼠标相关事件见控制台 `MOUSE MODE phase=...` 与既有 `HID BUTTON ...` 日志；脱敏，不含坐标与窗口标题。
- 方向键移动链路：`phase=edge button=<键> edge=press/release pressing=<数量>`、`phase=move_stopped reason=release_debounce|mode_off`、
  `phase=action button=<键> action=<动作>`。排查“一按冲到边缘”时，先确认松键有对应 `edge=release` 且随后出现 `move_stopped`。

## 验证边界

- 自动化：覆盖 `MouseModeTests`（固定映射、互换、passthrough、未激活解析、边缘消费、无启用开关）。
- 本机代理：`scripts/package-local-test-app.sh` 的 `public` 模式构建启动验证。
- 真实环境：需真实遥控器 + 蓝牙 + 辅助功能权限验收实际指针移动与点击；无实机证据时标记待验证。
- UI：按 `FEATURE_DEVELOPMENT.md` 截图门禁，PR 附中英文浅/深色、最小尺寸实际运行截图。
