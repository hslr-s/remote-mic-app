# 自定义模式（Custom Modes）测试手册

## 准备

- 真机（Siri Remote）通过蓝牙连接，辅助功能与输入监听权限已授予。
- 日志：`~/Library/Logs/RemoteMic/runtime.log` 中过滤 `CUSTOM MODE`。

## 用例

### 1. 创建模式 + 在按键映射页绑定切换动作

1. 打开「自定义模式」，输入名称「阅读」→「新建模式」，再建「演示」。
2. 给「阅读」设置指示圈：开启，选绿色；给「演示」选橙色（区分模式）。
3. 打开「按键映射」页，选一个空闲按键（如菜单键双击）→ 动作网格选「切换自定义模式」。
4. 展开的「目标模式」里选「阅读」；槽位摘要应显示「切换到：阅读」。
5. 再选另一个按键（如 TV 键单击）→「切换自定义模式」→ 目标选「演示」。
- 预期：两个槽位分别显示对应目标模式名，配置已落盘。

### 2. 切换进出

1. 双击菜单键（绑定切换到「阅读」）。
- 预期：光标处出现绿色常驻指示圈；日志 `CUSTOM MODE phase=toggle` +
  `phase=state result=on`。
2. 再次双击菜单键。
- 预期：指示圈消失，回普通模式；日志 `phase=state result=off`。
3. 在「阅读」激活时单击 TV 键（绑定切换到「演示」）。
- 预期：直接切到「演示」，指示圈变橙色。

### 3. 模式内映射与回退

1. 在「自定义模式」→「阅读」→ 模式内映射，给「上键单击」设为「向上翻页」。
2. 进入「阅读」，按上键。
- 预期：执行向上翻页；日志 `CUSTOM MODE phase=action`。
3. 在「阅读」激活时按一个未设置的键（如音量键）。
- 预期：按普通映射执行（回退语义）。
4. 退出「阅读」后按上键。
- 预期：恢复普通映射行为。

### 4. 指示圈配置

1. 关闭「显示模式指示圈」后进入该模式。
- 预期：不显示圈，但模式仍激活（映射生效）。
2. 重新开启，切换预设色板 / 自定义颜色 / 跟随系统。
- 预期：颜色即时生效，不同模式颜色不同。

### 5. 与鼠标模式互斥

1. 先进入鼠标模式（按其切换键），再按自定义模式切换键。
- 预期：退出鼠标模式并进入自定义模式。
2. 在自定义模式激活时按「切换鼠标模式」键。
- 预期：退出自定义模式并进入鼠标模式。

### 6. 删除与异常

1. 删除当前激活的模式。
- 预期：立即退出该模式，回普通模式。
2. 删除一个被切换动作引用的目标模式，回到按键映射页。
- 预期：该槽位显示橙色「模式已删除」提示；按它不切换、不误触发其他动作。
3. 配置导出/导入：普通映射含「切换自定义模式」动作。
- 预期：导出不报错，该绑定在导出配置中降级为「未设置」；导入后不影响其他绑定。
4. 应用重启。
- 预期：模式列表、切换绑定、模式内映射均保留；启动即为普通模式（激活态不保留）。

### 7. 边界（已知不支持）

- Apple Remote / Chromecast / 手机端按「切换自定义模式」绑定键。
- 预期：与鼠标动作一致的既有边界——不接管、不误注入按键（日志 `ignored reason=controller_action`）。

## 失败判定

- 按切换键无反应，或按一次后模式反复开关。
- 模式内映射未生效，或退出模式后普通映射被残留覆盖。
- 指示圈在关闭开关后仍显示，或退出模式后不消失。
- 鼠标模式与自定义模式同时生效。
- 日志出现 `phase=toggle` 但没有对应 `phase=state result=on/off`。

## 自动化与截图边界

- 自动化：`CustomModeTests`（modeID 载荷与 JSON 往返、旧配置兼容、槽位设置、
  控制器激活退出与删除退出、切换动作非 App 内部动作、本地化完整）。
- 截图：`SettingsScreenshotRenderer` 支持 `SECTION=customModes` 与
  `REMOTE_MIC_SETTINGS_SCREENSHOT_CUSTOM_MODES_FIXTURE=1`，生成模式页浅色中文/深色英文截图；
  按键映射页的「目标模式」选择器需在 real UI 中确认布局。
- 单元测试、构建、截图只证明各自边界；真实切换、互斥、指示圈与实机验收待现场完成。
