# 自定义模式（Custom Modes）测试手册

## 准备

- 真机（Siri Remote / 遥控器）通过蓝牙连接，辅助功能与输入监听权限已授予。
- 打开设置 → 「自定义模式」，确认侧栏出现该分区，页面默认为空态文案。
- 日志：`~/Library/Logs/RemoteMic/runtime.log` 中过滤 `CUSTOM MODE`。

## 用例

### 1. 空态与默认零影响

1. 不创建任何自定义模式。
2. 正常使用遥控器所有按键，确认行为与此前一致。
- 预期：无任何模式接管，日志无 `CUSTOM MODE` 记录。

### 2. 创建与切换

1. 输入名称「阅读」→ 点击「新建模式」；再建第二个模式「演示」。
2. 给「阅读」配置切换键：菜单键 + 双击；给「演示」配置：TV 键 + 单击。
3. 双击菜单键。
- 预期：光标位置出现常驻绿色指示圈（若开启指示圈）；日志出现
  `CUSTOM MODE phase=toggle` 与 `phase=state result=on`。
4. 再次双击菜单键。
- 预期：指示圈消失，回普通模式；日志 `phase=state result=off`。
5. 在「阅读」激活状态下单击 TV 键。
- 预期：直接切到「演示」模式（指示圈颜色变为「演示」的配置色）。

### 3. 模式内映射与回退

1. 在「阅读」的映射画布中给「上键单击」设为「向上翻页」。
2. 进入「阅读」模式，按上键。
- 预期：执行向上翻页，而非普通映射；日志 `CUSTOM MODE phase=action`。
3. 在「阅读」激活状态按一个未设置的键（如音量键）。
- 预期：按普通映射执行（回退语义）。
4. 退出「阅读」后按上键。
- 预期：恢复普通映射行为。

### 4. 指示圈配置

1. 关闭「显示模式指示圈」后进入该模式。
- 预期：不显示圈，但模式仍激活（映射生效）。
2. 重新开启，切换预设色板 / 自定义颜色 / 跟随系统。
- 预期：颜色即时生效；指示圈颜色随所选变化。

### 5. 与鼠标模式互斥

1. 先进入鼠标模式（按其切换键），再按自定义模式切换键。
- 预期：退出鼠标模式并进入自定义模式。
2. 在自定义模式激活时按「切换鼠标模式」键。
- 预期：退出自定义模式并进入鼠标模式。

### 6. 删除与冲突

1. 删除当前激活的模式。
- 预期：立即退出该模式，回普通模式。
2. 两个模式配置同一按键 + 触发。
- 预期：第二个模式页显示橙色冲突提示；实际切换命中先创建的模式。

### 7. 异常恢复

- 应用重启。
- 预期：模式列表与配置保留；激活状态不保留（启动即为普通模式）；
  模式切换、映射、指示圈均正常。

## 失败判定

- 按切换键无反应，或按一次后模式反复开关。
- 模式内映射未生效，或退出模式后普通映射被残留覆盖。
- 指示圈在关闭开关后仍显示，或退出模式后不消失。
- 鼠标模式与自定义模式同时生效（如方向键既移动指针又触发普通动作）。
- 日志出现 `phase=toggle` 但没有对应 `phase=state result=on/off`。
